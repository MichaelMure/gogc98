Each row is one 8 KB heap page, Go's unit of memory management. The Go allocator only ever puts same-size-class objects in a page (never a mix). Box width is proportional to an object's byte size relative to one page, so a page of many tiny objects looks like a dense strip of slivers, and a single object bigger than one page fills every page it spans edge to edge.
row label id: green = real page   dim = reclaimed/unused
annotation: 128B = the size class of objects on this page, colored blue–red by scale (log, 8 B–32 KB)   +N = N more objects here aren't individually tracked   i/n = page i of n of one object spanning multiple pages
