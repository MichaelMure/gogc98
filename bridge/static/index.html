Each row is one 8 KB heap page, Go's unit of memory management. The Go allocator only ever puts same-sized objects in a page (never a mix), which is why every box in a row is the same size, and why one page's size tells you what kind of page it is.
row label id: green = real page   dim = reclaimed/unused
annotation: 128B = size of each box on this page (not the page itself)   +N = N more boxes exist here but don't fit in the row   i/n = page i of n of one large object
minimap (one tick per tracked page across the whole heap, not just what's currently in view): yellow = in the current view   green (brighter = more recently active) = tracked but elsewhere
